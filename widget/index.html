🤖 AI Agent Widget - Installation Guide

Add a working AI assistant to any website in seconds. The widget handles conversations, appointment bookings, FAQs, and more using your business information.

Quick Start (3 steps)

Step 1: Get Your Tenant ID

Create a business profile in the onboarding form. You'll receive a tenant_id and an embed script. Save the tenant_id.

Step 2: Add This Script to Your Website

Paste this into the <head> or before </body>:

<script 
  src="https://your-backend-domain.com/widget/agent.js" 
  data-tenant-id="YOUR_TENANT_ID">
</script>
Step 3: Done!

A chat button will appear in the bottom-right corner of your website. Your customers can now chat with your AI assistant.

✓ The widget is fully self-contained - no other code changes required

Features

  • Appointment Bookings: AI detects booking requests and collects customer info
  • Conversation Memory: Assistant remembers what was discussed in same session
  • Business Context: Answers based on your business info and knowledge base
  • Handoff Detection: Escalates complex issues to humans when needed
  • Mobile Friendly: Works on all devices and screen sizes
  • Session Tracking: Maintains conversation history per visitor

Configuration

The widget needs to know where your backend API is running. Update the API URL in agent.js:

const API_BASE_URL = 'http://localhost:8000/api'; // Change this to your backend
⚠️ For Production:
  • Change API_BASE_URL to your actual backend domain (with HTTPS)
  • Enable CORS for your domain in the backend
  • Host agent.js on a CDN or your server

Customization

You can customize the widget appearance by editing the CSS in agent.js:

  • Colors: Change #667eea and #764ba2 for gradients
  • Position: Modify bottom: 20px; right: 20px; in .ai-agent-widget
  • Size: Adjust width: 400px; height: 600px; for chat window
  • Welcome Message: Edit the message in the demo section

What's Next?

  1. Start the backend API: uvicorn app.main:app --reload
  2. Create a business profile in the onboarding form
  3. Get your tenant ID from the response
  4. Embed the widget on your test website
  5. Chat with your AI assistant!

Backend API Endpoints

The widget uses these endpoints:

  • POST /api/chat - Send message and get response
  • POST /api/tenants - Create business profile (from onboarding)
  • POST /api/tenants/{tenant_id}/knowledge - Add business knowledge
